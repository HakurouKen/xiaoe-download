# 自包含 CLI 构建

`tsdown.config.ts` 是唯一构建配置。主 CLI、共享 chunk 和第三方许可声明统一生成到 `dist/`，每次构建清理该目录；运行产物不要求用户安装 npm 依赖。保留开发用源码映射，发布时不交付。构建只允许 Node 内置模块作为外部 ESM 导入，脱离项目的实际运行由发布验收验证。

Puppeteer 带有浏览器安装分支，其中可选代理及 ZIP 解压依赖不属于项目使用的 Chrome CDP 连接路径。构建将这些分支替换为明确的“不支持自动安装 Chrome”错误，避免打包无关安装依赖；仍需验证 WebSocket 连接没有回归。

构建完成钩子按实际参与产物的模块收集许可证及源文件内嵌声明，生成一份 `dist/third-party-licenses.txt`。`licenses/` 保存上游发布包缺失的 Apache-2.0 标准文本和 boolbase 许可文本；缺少无法处理的依赖许可时构建失败。这些模板不额外复制进 Skill，生成声明随下载器产物一次交付。
